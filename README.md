Employee Management System

A web-based Employee Management System developed using HTML, CSS, and JavaScript.

📌 About the Project

This project is designed to manage employee information through a simple and user-friendly web interface.

🚀 Features

- Add employee details
- View employee details
- Edit employee information
- Delete employee information
- Search employees
- Responsive user interface
- Data management using JavaScript

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Git & GitHub

📂 Project Structure

employee-management-system/
│
├── index.html
├── style.css
├── script.js
├── images/
└── README.md

▶️ How to Run

1. Download or clone this repository.
2. Open the project folder.
3. Open "index.html" in your browser.
